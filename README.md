# zepto-sql-data-analysis
This project focuses on analyzing a real-world e-commerce inventory dataset inspired by Zepto using SQL in PostgreSQL.

The goal of this project is to simulate how a data analyst works in a real company environment — starting from raw data to extracting meaningful business insights.

The workflow includes:

Database creation and schema design
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Business problem solving using SQL

This project demonstrates how SQL can be used to analyze product pricing, discounts, stock availability, and revenue estimation in an e-commerce setting.

1. Database Creation & Schema Design

A structured database is created using PostgreSQL. Tables are designed with appropriate data types, constraints, and primary keys to ensure data integrity and efficient querying.

2. Data Cleaning & Preprocessing

Raw data is cleaned using SQL techniques:

Handling missing values
Removing duplicates
Fixing inconsistent data
This step ensures high-quality data for accurate analysis.

3. Exploratory Data Analysis (EDA)

SQL queries are used to explore and understand the dataset:

Product category distribution
Price and discount analysis
Stock availability insights
Identifying high-value and low-value products

Aggregation functions like SUM(), AVG(), COUNT(), and GROUP BY are used extensively.
